# Preguntas para Polyglot Commonwealth

Estas son las cuatro cosas que necesitamos que la academia nos confirme para seguir construyendo la aplicación. Con una respuesta corta a cada una nos basta. Si algo no se sabe todavía, "no lo sabemos" también es una respuesta útil.

## 1. Alojamiento y correo

La aplicación necesita un servidor propio y enviar correos (por ejemplo, para recuperar una contraseña). El plan actual del sitio web no suele servir para eso.

1. ¿Qué plan de alojamiento tienen hoy para el sitio web y quién lo administra?
2. ¿Tienen correos con el dominio de la academia (por ejemplo, `info@...`)? ¿Podemos crear una dirección para enviar los avisos de la aplicación?
3. ¿Quién pagará el servidor y el correo cuando la aplicación esté en uso, y desde qué fecha?
4. ¿A nombre de quién deben quedar las cuentas de dominio, de Google Play y de Apple Developer?

## 2. Datos personales

La aplicación guarda datos de aspirantes y estudiantes, incluidos menores de edad, y la Ley 1581 de 2012 exige reglas claras sobre ellos.

1. ¿La academia tiene una política de tratamiento de datos personales escrita? Si la tiene, ¿nos pueden compartir una copia?
2. ¿Quién es la persona responsable de atender las solicitudes de consulta o eliminación de datos?
3. ¿Por cuánto tiempo conserva hoy la academia los datos de quienes se inscriben y no se matriculan, y los de quienes dejan de estudiar?
4. ¿Las clases se grabarían? Si es así, ¿quién podría verlas y por cuánto tiempo?

## 3. Contenido de las lecciones

Las lecciones y ejercicios de cada idioma son contenido, no programación, y alguien con conocimiento pedagógico debe escribirlo y revisarlo.

1. ¿Quién de la academia redactará y revisará las lecciones y los ejercicios de cada idioma?
2. ¿Con qué idioma y nivel conviene empezar?
3. ¿Ya existe material (guías, presentaciones, ejercicios) que podamos usar? ¿La academia es dueña de sus derechos?
4. ¿Hasta qué fecha puede entregar cada persona el material de su idioma?

## 4. Reemplazo del panel actual

La nueva aplicación incluirá una sección de gestión para el Administrador y **no** se conectará al panel actual ni traerá sus datos.

1. ¿Están de acuerdo con que la aplicación reemplace al panel actual para administrar inscripciones, estudiantes, certificados, ciclos de pago y multimedia?
2. Los datos que hoy están en el panel no pasarán a la aplicación nueva. ¿Cuánto tiempo mantendrán el panel actual para consultarlos?
3. ¿Qué personas de la academia serán Administradores de la aplicación?
4. Mientras la aplicación no esté lista, ¿el formulario de inscripción del sitio web sigue funcionando igual?
